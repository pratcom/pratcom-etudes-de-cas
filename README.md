# Pratcom – Études de cas

Extension WordPress de Pratcom Média : type de contenu « Études de cas », séparé des articles du blogue (secteurs, services, fiche projet, gabarits, compatible WPML).

Les sites qui l'utilisent se mettent à jour depuis ce dépôt : WordPress lit l'en-tête `Version:` de `pratcom-etudes-de-cas.php` sur la branche `main` et propose la mise à jour quand elle est plus haute que la version installée. Publier une version = augmenter `Version:` et `PEDC_VERSION` sur `main`, et ajouter l'entrée au Changelog de `readme.txt`.

Détails : voir `readme.txt`.
